# Spec Delta

## Purpose

Гарантирует, что запуск бота по расписанию внутри контейнера использует ту же конфигурацию, что задана контейнеру, а не пустое окружение cron.

## ADDED Requirements

### Requirement: Запуск по расписанию получает конфигурацию контейнера
Система MUST передавать запуску бота по расписанию значения `GOOGLE_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_GROUP_ID` и `CALENDAR_ID`, заданные контейнеру при старте.

#### Scenario: Переменные заданы
- **WHEN** контейнер запущен с заданными четырьмя переменными и cron запускает бота
- **THEN** бот видит те же значения и не завершается ошибкой из-за их отсутствия

#### Scenario: Переменная не задана
- **WHEN** контейнер запущен без одной из переменных
- **THEN** запуск по расписанию видит её пустой, а контейнер при этом стартует и работает

### Requirement: Значения секретов не раскрываются в логах
Система MUST NOT выводить значения переменных конфигурации в логи контейнера при старте и при запусках по расписанию.

#### Scenario: Старт контейнера
- **WHEN** контейнер стартует и подготавливает окружение для cron
- **THEN** вывод `docker logs` не содержит значений токена и ключа API
