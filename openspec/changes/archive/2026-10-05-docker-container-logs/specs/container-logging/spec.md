# Spec Delta

## Purpose

Делает результат каждого запуска бота наблюдаемым через стандартные логи Docker, чтобы эксплуатацию можно было вести без захода внутрь контейнера.

## ADDED Requirements

### Requirement: Вывод запуска доступен в логах контейнера
Система MUST направлять stdout и stderr каждого запуска бота по расписанию в логи контейнера, доступные через `docker logs`.

#### Scenario: Успешный запуск
- **WHEN** cron запускает бота и бот печатает сообщения о результате
- **THEN** эти сообщения видны в выводе `docker logs <контейнер>`

#### Scenario: Ошибка при запуске
- **WHEN** бот завершается с ошибкой или трассировкой исключения
- **THEN** текст ошибки виден в выводе `docker logs <контейнер>`

### Requirement: Вывод появляется без задержки
Система MUST выводить строки лога по мере их печати, а не после завершения процесса.

#### Scenario: Сообщение при долгом запуске
- **WHEN** бот печатает строку, а запуск ещё не завершён
- **THEN** строка появляется в `docker logs` до завершения запуска
