# Spec Delta

## Purpose

Обеспечивает надёжную выкладку новой версии бота в Docker Swarm: одно обновление сервиса за деплой и отсутствие конкурирующих деплоев.

## ADDED Requirements

### Requirement: Деплой обновляет сервис без конфликта обновлений
Система MUST выполнять за один деплой одно обновление сервиса планировщика на образ выбранного тега и MUST завершаться успешно, если сервис сошёлся к новой версии.

#### Scenario: Успешный деплой
- **WHEN** запускается деплой из ветки `main` с новым образом
- **THEN** сервис обновляется один раз и шаг деплоя завершается без ошибки `update out of sequence`

### Requirement: Деплои не выполняются параллельно
Система MUST NOT запускать два деплоя в продакшен одновременно, при этом уже идущий деплой MUST NOT прерываться новым.

#### Scenario: Два коммита подряд в main
- **WHEN** второй деплой запускается, пока первый ещё выполняется
- **THEN** второй ждёт завершения первого, а первый доходит до конца
